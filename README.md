# Tomiño, parroquia a parroquia

Mapa interactivo dos resultados electorais de Tomiño por mesa e parroquia: municipais (1979–2023), autonómicas (1985–2024), xerais (1977–2023) e europeas (1987–2024), por bloques (esquerda e dereita) ou por partidos.

- https://mapa-electoral-tomino.villa18241.workers.dev
- https://villadumorin.github.io/mapa-electoral-tomino/ (copia, por se un dos dous está bloqueado)

A web é `docs/index.html`, unha páxina autónoma cos datos dentro (tamén en `docs/tomino.json`). Publícase en Cloudflare (`wrangler.jsonc`) e en GitHub Pages (cartafol `docs/` da rama `main`); cada cambio que se suba aquí actualiza as dúas.

Fontes: Ministerio do Interior (infoelectoral; xerais, municipais e europeas por mesa), Xunta de Galicia (abertos.xunta.gal), IGE e BOP de Pontevedra. Límites das parroquias: IET (Xunta), vía OpenStreetMap (ODbL).
